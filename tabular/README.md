# Tabular Project

This repository applies machine learning to predict sleep disorder risk from lifestyle features from the "Sleep Health and Lifestyle" Kaggle dataset. (https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset))

## Project Overview
The task is to use a tabular dataset of 12 features for 374 people to train and test a machine learning model that predicts the sleep disorder risk based on lifestyle. This study was approached by formulating an initial question, performing exploratory data analysis, feature engineering, cleaning and preprocessing the data, splitting, and training three different machine learning models, logistic regression, random forest classifier, and XG Boost, to compare performance and identify the most influential features. Amongst the three separate machine learning models, the XG Boost scored the highest accuracy at 96.00% and precision at 96% for sleep disorder not present and 97% for sleep disorder present.
